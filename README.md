# Python Budget App

A Python budget management app built using object-oriented programming.

## Features

- Create budget categories
- Make deposits
- Make withdrawals
- Transfer money between categories
- Check category balances
- Track spending

## Concepts Used

- Python classes and objects
- `__init__` and `self`
- Attributes and methods
- Lists and dictionaries
- Loops and conditionals
- Object-oriented programming

## How to Run

Run the program with Python:

python budget-app.py

## Purpose

This project was built to practice Python object-oriented programming and managing financial transactions using classes and methods.
